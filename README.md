# SkillSprint - Internship Tracker

SkillSprint is a small project I built to keep track of internship applications in one place. I wanted a simple way to save company names, job roles, deadlines, and application status instead of managing everything separately.

### Feature

- Add internship details
- Track application status
- View total internships and application progress
- Save details in the browser

### Built With

- HTML
- CSS
- JavaScript
